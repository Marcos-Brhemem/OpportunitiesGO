## 🚀 Tecnologias

Backend

Golang: Para desenvolvimento da API.

SQLite: Banco de dados para armazenar as informações.

Swagger: Para a documentação e teste da API.

Frontend

React: Para construção da interface do usuário.

Material UI: Biblioteca de componentes estilizados para React.

## 💻 Projeto

CRUD de vagas de emprego:

Cadastrar novas vagas.

Editar informações de vagas existentes.

Excluir vagas.

Listar vagas com filtros.

Documentação completa da API utilizando o Swagger.

Interface amigável e moderna para interação com as funcionalidades da API.

Desenvolvido com React (JavaScript).

Uso da biblioteca Material UI para uma experiência visual limpa e responsiva.

Sistema de filtros para busca eficiente de vagas.
